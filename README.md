# Решение демонстрационного экзамена 2027

Репозиторий посвящён подготовке и разбору заданий демонстрационного экзамена по специальности **09.02.06 Сетевое и системное администрирование**.

Основа — КИМ **09.02.06-1-2027**.

В репозитории будут постепенно добавляться решения для разных вариантов стенда. Каждый вариант будет разбираться отдельно, с командами, скриншотами и примечаниями по выполнению задания.

Экзамен включает три основных задания:

- **Задание 1 — Настройка сетевой инфраструктуры**
- **Задание 2 — Организация сетевого администрирования**
- **Задание 3 — Эксплуатация объектов сетевой инфраструктуры**

> **ВАЖНО:** команды, имена интерфейсов, IP-адреса и другие параметры могут отличаться в зависимости от варианта и стенда. Перед выполнением команд сверяйтесь со своим заданием.
